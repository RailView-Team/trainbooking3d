# Backend

This directory contains the Express API for AeroRail.

## Included

- API server: [src/server.js](src/server.js)
- Database: [src/db.js](src/db.js)
- Routes: [src/routes](src/routes)
- Middleware: [src/middleware](src/middleware)
- Utilities: [src/utils](src/utils)
- Database schema and seed scripts: [database](database)

## Run

```bash
npm install
npm run dev
```

The API listens on the configured port and exposes routes under /api.
